# Project Features

## Retail Sales Analytics & Inventory Management System

# Overview

This project is an enterprise-level SQL analytics solution designed to demonstrate modern database development, business intelligence, and advanced analytical reporting using Microsoft SQL Server.

The project simulates a complete retail ecosystem and transforms transactional data into business insights through **375 business KPIs**.
