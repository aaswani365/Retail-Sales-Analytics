# Project Learnings

## Retail Sales Analytics & Inventory Management System

---

# Overview

The Retail Sales Analytics & Inventory Management System was developed to strengthen practical SQL skills while solving real-world retail business problems.

The project covers the complete lifecycle of database development, business analytics, and executive reporting using Microsoft SQL Server.

Throughout the development of this project, several technical, analytical, and business concepts were learned and applied.

---

# Technical Learnings

## Database Design

During this project, I learned how to:

* Design a relational database
* Apply database normalization (3NF)
* Create scalable database architecture
* Define primary and foreign keys
* Create lookup, master, and transaction tables
* Maintain referential integrity
* Build production-ready schemas
