# Repository Guide

## Retail Sales Analytics & Inventory Management System

---

# Repository Overview

This repository contains a complete end-to-end SQL analytics project developed using Microsoft SQL Server.

The project demonstrates enterprise database design, business intelligence, analytical reporting, and executive dashboard development through **375 business KPIs**.
