# Project Overview

The **Retail Sales Analytics & Inventory Management System** is an enterprise-grade SQL analytics project designed to simulate a modern retail business environment.

The project demonstrates how raw transactional data can be transformed into meaningful business intelligence using Microsoft SQL Server. It covers the complete analytics lifecycle—from database design and data modelling to advanced SQL querying, executive reporting, and dashboard-ready datasets.

Built with scalability, maintainability, and real-world business scenarios in mind, the project showcases advanced SQL techniques and delivers actionable insights for multiple business functions.

---

# Project Objectives

The project was developed with the following objectives:

* Design a normalized relational database.
* Implement enterprise-level SQL development standards.
* Generate business insights through analytical SQL.
* Build dashboard-ready datasets for Business Intelligence tools.
* Create reusable SQL scripts for reporting.
* Demonstrate advanced SQL concepts for professional portfolios.
* Simulate real-world retail business analytics.

# Database Architecture

The database follows a **three-layer architecture**.

## Lookup Tables

Reference data used throughout the system.

* Brand
* Category
* SubCategory
* OrderStatus
* PaymentMethod
* PaymentStatus
* ReturnReason
* ReturnStatus

## Master Tables

Core business entities.

* Customer
* Employee
* Product
* Store
* Supplier

## Transaction Tables

Operational business data.

* Order
* OrderItem
* Inventory
* Payment
* Return
